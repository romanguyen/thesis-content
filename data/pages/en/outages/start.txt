====== Outages ======

Information about planned maintenance and limitations of the computing infrastructure. Check the MetaVO operational overview for current announcements.

  * [[https://metavo.metacentrum.cz/en/news/outages.jsp|Current MetaVO outages]]
  * [[mailto:meta@cesnet.cz|Contact support]]

**Local notice archive:** the entries below describe scheduled maintenance windows from April 2026. They are not a live list of current incidents.

===== Planned maintenance: frontends and scheduler =====
  * **Window:** 2026-04-14, 07:00–11:00 CEST
  * **Impact:** short interruption of login and scheduler commands
  * **Affected services:** selected frontend nodes and the PBS scheduler

If login or scheduler commands are unavailable during the stated window, check the operational announcements for details. For a persistent problem, contact support with the frontend name and any error message.

===== Storage maintenance: scratch metadata =====
  * **Window:** 2026-04-16, 06:00–08:00 CEST
  * **Impact:** temporary slower access to selected scratch paths
  * **Affected services:** scratch storage metadata services

For data-access problems, include the affected path, job ID and time of the problem in your support request. This record describes an announced limitation, not the service's current availability.

===== Where to follow current incidents =====

Use the [[https://metavo.metacentrum.cz/en/news/outages.jsp|MetaVO operational overview]] for the latest announcements. See the [[https://docs.metacentrum.cz/en/docs/support/outages|outage documentation]] for further information.

Contact [[mailto:meta@cesnet.cz|meta@cesnet.cz]] for unexpected problems.
