====== Top Navigation Variant ======

This page collects links for the second interface version where navigation is placed on top.
The style is inspired by CESNET service pages, but all content remains MetaCentrum-specific.

===== Notes =====

  * `layout=top` switches the navigation placement.
  * `style=cesnet` applies the blue/orange top-menu visual variant.
  * Without these parameters, the default left-sidebar layout is used.
